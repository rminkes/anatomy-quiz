Anatomy Quiz

Image-based muscle identification and recall

Developed by Orlando College of Osteopathic Medicine

  • Quiz by Region — select a specific anatomical region from the dropdown, then answer questions about the muscles in that region.
  • Random Quiz — select a broad muscle group (e.g. Upper Extremity, Head & Neck) and the number of questions you want, then press Start →. A random selection of questions will be drawn from that group.
  • Question Types — use the buttons below the region selector to choose which types of questions you are asked. All types are active by default. Beginners may want to start with Identify Muscle only — deselect the others to focus on recognising muscles from images before progressing to more detailed questions.
  • Study — browse any region as a reference. Select a region from the dropdown and click any muscle to expand its full anatomical details.
  • Images — click any image to enlarge it. If an image fails to load, use the ↺ Retry button.
